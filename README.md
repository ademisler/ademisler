## Selected projects

- **[BrowserPair](https://browserpair.com)** — Lets AI agents work in your existing Chrome browser with scoped permissions, human approvals, and verifiable actions. [Chrome extension](https://chromewebstore.google.com/detail/agdomhjeahcbelohnmjmbldeldclnoof)
- **[RunOnMine](https://runonmine.github.io/)** — A local-first MCP gateway for giving AI controlled access to your computer, with local policy, approvals, and audit. [Open source](https://github.com/ademisler/RunOnMine)
- **[Myna Player](https://myna-player.github.io/)** — An open-source video player that transcribes ahead, translates with context, and keeps subtitles in sync. [Open source](https://github.com/ademisler/Myna-Player)
- **[InvoiceRig](https://invoicerig.com/en)** — A France-focused testing platform for e-invoicing integrations, combining technical validation with reproducible provider-sandbox evidence.
- **[Ternrise](https://ternrise.com/)** — An immigration and visa expert marketplace connecting clients with consultants for specialist advice and project-based work.
